From clone to first invoice.

Four steps stand between a fresh checkout and a running billing system.

01

Deploy

Clone the repository and run it directly with Maven — no containers required to get started.

mvn spring-boot:run
02

Configure your app

Set up your database connection and adjust core platform properties to fit your business logic.

03

Manage subscribers

Register new users, delete or update profiles, suspend accounts, issue custom invoices, and manually adjust balances from a single dashboard.

04

Bill & invoice

Every charge lands in an immutable transaction ledger, converted across currencies with a full audit trail.

What's in the ledger.

Everything a subscription business needs on day one — nothing it has to bolt on later.

Role-based security

Session-based authentication with granular role separation between admin and client surfaces — no shared attack surface.

Full user lifecycle

Complete CRUD across the subscriber lifecycle, from signup to churn.

Multicurrency & i18n

ISO 4217 currency handling with bidirectional exchange-rate entry against a fixed base currency.

Complete transaction audit

Every ledger entry is immutable and traceable — base amount, subscriber amount, and the exact rate applied.

Built on a production-ready foundation.

No exotic dependencies. Just the tools already trusted to run critical infrastructure.
